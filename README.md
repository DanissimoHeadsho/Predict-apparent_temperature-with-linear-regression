# Веб-приложение для предсказания температуры по ощущениям с помощью линейной регрессии
![](images/screen.png)
## Краткое описание работы веб-приложения
Приложение собирает данные о погоде (**фактическую температуру, температуру по ощущениям, влажность и скорость ветра**) за выбранный промежуток времени в конкретной геолокации (по широте и долготе или по выбору города). Затем с помощью **алгоритма градиентного спуска** модель устанавливает линейную зависимость между температурой по факту, влажностью и скоростью ветра, обучаясь на собранных данных. После обучения модель может предсказать температуру по ощущениям, выводит метрики качества обучения, а также показывает худшие результаты предсказаний на тестовой выборке. Линейная регрессия реализована **вручную** через NumPy

## Структура проекта

- `weather_loader.py` — загрузка данных с помощью Open-Meteo API за выбранные годы в выбранной геолокации
- `load_data.py` — скрипт с вводом диапазона лет и координат.
- `model.py` — класс `GDRegressor`, реализующий градиентный спуск.
- `pipeline.py` — стандартизация данных c помощью класса StandardScaler, обучение модели, расчет метрик, поиск самых неточных прогнозов.
- `app.py` — приложение на Flask.
- `templates/index.html` — шаблон страницы и небольшой JavaScript код для ввода города и автоматической подстановки его координат.
- `static/style.css` — стили.
- `data/weather_dataset.csv` - подгруженные данные о погоде.
## Немного теории

### Линейная зависимость
Линейные методы предполагают, что между признаками объекта и целевой переменной существует линейная зависимость, то есть:  
$\hat{y} = w_1x_1 + w_2x_2 + ... + w_kx_k+b$
где  $\hat{y}$  - целевая переменная (что мы хотим предсказать),  $x_i$  -  i-ый признак объекта  x ,  $w_i$  - вес  i-го признака,  b  - bias (смещение, свободный член).
В нашем случае целевая переменная - это температура по ощущениям, 1ый, 2ой и 3ий признаки - температура по факту, влажность и скорость ветра соответственно, а $w_i$ и b - те самые коэффициенты, которые подбирает модель. 

> Очевидно, что температура по-ощущениям не выражается полностью линейно через выше помянутые признаки, но так как они оказывают наибольшее влияние на целевую переменную, то с их помощью можно составить примерную зависимость.

### Градиентный спуск
Метод градиентного спуска заключается в том, чтобы найти локальный минимум целевой функции, т.е. подобрать такие $w_i$, чтобы уменьшить ошибку модели. Алгоритм работает итеративно, его сходимость зависит от скорости обучения и количества итераций.   
В нашем случае целевой функцией будет являться $\frac{MSE}{2}$, т.е.  
$J(w) = \frac{1}{2m}\sum_{i=1}^{m}{(h_w(x_i) - y_i)^2}$, где:  
$h_w(x_i)$ - предугаданное моделью значение целевой переменной, $y_i$ - реальное значение целевой переменной, $m$ - длина вектора $y$, $x_i$ - вектор значений признаков на i-ой строке.  
Общая формула для обновления коэф-ов:  
$w_{new} = w - {\alpha}{\nabla}J(w)$, где $\alpha$ - скорость обучения, $w$ - вектор текущих коэф-ов, $w_{new}$ - вектор обновленных коэф-ов:  
Посчитав градиент целевой функции получим следующую формулу:  
$w_{new} = w - {\alpha}\frac{1}{m}\sum_{i=1}^{m}({h_w(x_i) - y_i})x_i$  
Она и используется в *model.py* (в матричной форме).
